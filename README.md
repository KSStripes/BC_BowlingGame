# BC Bowling Game

A Unity bowling game prototype created for a Graphics Animation course.

## Overview

This project is a small 3D bowling game with aiming, adjustable throw force, physics-based ball movement, pin detection, scoring, and round progression.

## What I Built

- Bowling alley scene
- Aim arrow for lining up throws
- Adjustable throw force
- Physics-based ball launch
- Pin knockdown detection
- Two-ball round flow
- Five-round scoring system
- Ball spawning and camera reset
- On-screen game statistics and controls
- Restart option

## Tech Stack

- Unity
- C#
- Unity Physics
- OnGUI UI
- Universal Render Pipeline
